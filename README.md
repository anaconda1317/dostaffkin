# DoStaffkin

Приложение на Angular для расчёта доставки и отслеживания отправлений.

## Что делает
- Страница "Главная" — информационный вход в сервис.
- Страница "Заказ" — ввод адресов отправления и получения, выбор размера/типа доставки, расчёт маршрута и стоимости.
- Страница "Отследить" — получение информации по номеру доставки.

## Технологии
- Angular 21
- TypeScript 5
- RxJS
- Angular Router
- Angular Forms
- Yandex Maps API (поля подсказки и маршруты)
- HTTP-запросы к внешнему API `https://testologia.ru/delivery`

## Структура
- `src/app/app.ts` — корневой компонент с `router-outlet`
- `src/app/app.routes.ts` — маршруты: `/`, `/order`, `/track`
- `src/app/pages/order` — страница заказа и расчёта доставки
- `src/app/pages/track` — страница трекинга
- `src/app/services/delivery-api.ts` — HTTP-сервис для создания заказа и получения статуса

## Команды
```bash
npm install
npm start    # dev server
npm run build
npm run watch
npm test
```

## Запуск
1. Установить зависимости: `npm install`
2. Запустить приложение: `npm start`
3. Открыть в браузере: `http://localhost:4200`

## Особенности
- Расчёт стоимости на основе расстояния маршрута и выбранного размера отправления
- Быстрый и обычный тарифы
- Отправка заявки на внешний API
- Валидация формы и вывод трек-информации
